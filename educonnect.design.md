# EduConnect Design System

## Domain Tag
Educational App

## Selected Design System
Domain Tag: Educational App
Color Palette: Option 1
Typography: Option 1
Rationale: Playful indigo and energetic orange create a welcoming, engaging atmosphere for students and teachers, while Baloo 2 + Comic Neue keep the UI friendly and approachable — matching the "basic but interactive" brief.

## Design Aesthetic
Claymorphism — Soft 3D, rounded, colorful, friendly surfaces with subtle depth. Perfect for an educational platform that needs to feel approachable.

## Type Scale
Ratio: 1.250 (Major Third)
- 0.64rem / 0.8rem / 1rem / 1.25rem / 1.563rem / 1.953rem / 2.441rem

## Layout
Single-page app with view switching via JavaScript. Sections stacked vertically with smooth scroll navigation. Auth state controls visibility of Dashboard section.
